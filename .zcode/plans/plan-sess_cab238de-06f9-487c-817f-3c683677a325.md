# خطة تنفيذ تحسينات SEO والتقنية لموقع MacBroom

تنظّر الخطة بالأولويات (حرج → مهم → ثانوي). كل التعديلات على الكود ستراعي تحذير `AGENTS.md` بقراءة أدلة Next.js من `node_modules/next/dist/docs/` قبل كتابة أي كود (إصدار 15.5 مخصّص/غير قياسي).

## 🔴 المرحلة 1 — إصلاحات حرجة (الأساس)

### 1.1 تحديث `metadata` الجذر في `src/app/layout.tsx`
إضافة:
- `metadataBase: new URL("https://macbroom.com")`
- `title: { default: "...", template: "%s | MacBroom" }` — قالب عناوين لكل الصفحات
- `openGraph` كامل (title, description, url, siteName, locale:"en_US", type:"website", images)
- `twitter: { card: "summary_large_image", title, description, images }`
- `alternates: { canonical: "/" }`
- `keywords`, `authors`, `creator`, `applicationName`
- `robots: { index: true, follow: true, googleBot: {...} }`

### 1.2 إنشاء صورة OG/Twitter افتراضية
إنشاء `src/app/opengraph-image.tsx` (صورة ديناميكية عبر ImageResponse) أو وضع صورة `public/og.png` ثابتة (1200×630) وربطها. نفس الشيء لـ `twitter-image`.

### 1.3 إضافة `metadata` لكل صفحة (عبر layout.tsx فرعي حيث يلزم)
- الصفحات الثابتة (`/privacy`, `/terms`, `/refund`, `/support`, `/thank-you`): تصدير `metadata` بعنوان ووصف وcanonical مخصص.
- `/contact`, `/signin` (مكونات عميلة): إنشاء `layout.tsx` مجاور في نفس المجلد لتصدير metadata (الحل المعتمد لـ App Router).
- `/` و `/profile`: نفس المعالجة.

### 1.4 تأكيد الـ canonical لكل صفحة
كل metadata يتضمن `alternates: { canonical: "<route>" }`.

## 🟡 المرحلة 2 — تحسينات مهمة

### 2.1 البيانات المنظمة (JSON-LD)
إضافة مكوّن `<script type="application/ld+json">` في `layout.tsx` أو صفحات محددة لـ:
- **`SoftwareApplication`** + **`Product`** (مع السعر من Pricing.tsx، نظام التشغيل macOS، تصنيف)
- **`Organization`** (الاسم، الشعار icon.png، رابط التواصل)
- **`FAQPage`** (مولّد ديناميكياً من `src/lib/faq-data.ts`) في الصفحة الرئيسية و/أو `/support`

### 2.2 Web Manifest
إنشاء `src/app/manifest.ts` (أو `public/manifest.webmanifest`) مع name, short_name, icons, theme_color, background_color, start_url, display. وربطه في metadata.

### 2.3 الأيقونات
- إضافة `src/app/icon.png` و `src/app/apple-icon.png` (من `public/icon.png` الموجود) ليتولّى Next.js ربطها تلقائياً.
- إنشاء/نسخ `favicon.ico` في `src/app/` للتوافق القديم.

### 2.4 تحديث `public/sitemap.xml`
- إضافة `/support`.
- إضافة `<lastmod>` لكل رابط (التاريخ الحالي أو تاريخ آخر تعديل).
- إضافة `<xhtml:link rel="alternate" hreflang="en" .../>` إن لزم.

### 2.5 تحديث `public/robots.txt`
- إضافة `Disallow: /signin`, `Disallow: /profile`, `Disallow: /thank-you`.
- إبقاء `/`, `/contact`, `/privacy`, `/terms`, `/refund`, `/support` مسموحة.

### 2.6 رؤوس الأمان — ملف `_headers` (لـ Cloudflare Pages)
إنشاء `public/_headers` يتضمن:
```
/*
  Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
  X-Content-Type-Options: nosniff
  X-Frame-Options: SAMEORIGIN
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: ...
```
(مع مراجعة CSP بعناية نظراً لتحميل lemon.js خارجياً وSupabase.)

### 2.7 صفحة 404 مخصصة
إنشاء `src/app/not-found.tsx` بتصميم يطابق ثيم الموقع (شعار، رسالة، زر العودة للرئيسية).

## 🟢 المرحلة 3 — تنظيف وتحسينات ثانوية

### 3.1 حذف الملفات اليتيمة من `public/`
`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`, `logo.png`.

### 3.2 `next.config.ts`
- تقييم إضافة `trailingSlash: false` صراحةً وتوحيد المسارات مع sitemap.

### 3.3 `.gitignore`
- التأكد من تجاهل `.DS_Store` (وإزالته من `public/`).

### 3.4 (اختياري) تحسين سرعة الصور
- النظر في استخدام `next/image` حيثما أمكن رغم `unoptimized: true`، أو إضافة عرض/ارتفاع صريح للصور لتقليل CLS.

## ✅ التحقق بعد التنفيذ
- تشغيل `npm run build` والتأكد من نجاح البناء (static export).
- فحص `out/index.html` للتأكد من ظهور وسوم OG وTwitter وcanonical وJSON-LD.
- التحقق من `out/robots.txt` و `out/sitemap.xml`.
- (اقتراح للمستخدم) استخدام أداة مثلRich Results Test / OpenGraph.xyz للتدقيق النهائي قبل النشر.

## ملاحظات للتنفيذ
- السأتحقق من وثائق Next.js 15.5 في `node_modules/next/dist/docs/` قبل كتابة كود Metadata/manifest.
- لن ألمس `appcast.xml` أو منطق Supabase/Lemon Squeezy.
- كل التغييرات محلية في ملفات الموقع/الإعداد دون مساس منطق العمل.
