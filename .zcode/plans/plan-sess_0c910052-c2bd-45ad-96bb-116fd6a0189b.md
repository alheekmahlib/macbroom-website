### المشاكل الثلاث المكتشفة

بعد مراجعة كود التطبيق في `/Users/hawazenmahmood/Documents/GitHub/MacBroom`، وجدت أن البنية التحتية موجودة بالكامل (schema + Edge Function) لكن بها 3 مشاكل تمنعها من العمل:

#### 1. ⚠️ خطأ base64 في توقيع Ed25519 (`lemon-webhook/index.ts` السطر 75-78)
```ts
// الحالي (خاطئ): يحوّل أحرف string إلى char codes بدلاً من فك تشفير base64
const privateKeyBytes = Uint8Array.from(atob(ED25519_PRIVATE_KEY), (c) => c.charCodeAt(0));
```
هذا يوقّع بـ bytes الـ ASCII string `"Gt/2mU4k..."` وليس المفتاح الحقيقي (32 bytes). النتيجة: التوقيع **لن يمرّ التحقق** في التطبيق عند العمل offline.

#### 2. الـ webhook يستمع لـ `license_key_created` فقط
لكن LS يُنشئ مفتاح LS الخاص عند هذا الحدث — وأنت تريد إنشاء مفتاح Supabase خاص (`MACBROOM-XXXX`). الأصح الاستماع لـ `order_created` أو `order_completed`.

#### 3. RLS على `licenses` مُغلق تماماً
الـ schema يقول: "Intentionally no permissive policies. RLS denies by default."
صفحة البروفايل تستخدم **anon key** لقراءة الـ licenses بـ `.eq("email", userEmail)` — لكن RLS يرفض هذا! **لذلك المفاتيح لا تظهر في البروفايل حتى لو وُجدت في الجدول.**
